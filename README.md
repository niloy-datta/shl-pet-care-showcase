## 🌟 Key Features & Architectural Highlights

### 1. Executive Visual Design System
- **Corporate Color Palette**: Primary Navy (`#0B1F3A`), Premium Teal (`#0DAF98`), Background White (`#FFFFFF`), Soft Background (`#F8FAFC`), Main Text (`#0F172A`), Accent Amber (`#F5B544`).
- **Typography & Grid**: Modern typography hierarchy with Plus Jakarta Sans and Inter, standard 12-column desktop grid with a maximum container width of 1240px, and responsive mobile stack.
- **Zero Third-Party CDN Bottlenecks**: Self-contained CSS and SVG icons eliminating runtime latency and preventing Flash of Unstyled Content (FOUC).

### 2. Product Engineering & Interactive Specifications
- **Male Dog Wraps**: Repositionable fur-safe fasteners, 360° leak-guard barriers, wetness indicator, and Japanese Sumitomo SAP core.
- **Female Dog Diapers**: Ergonomic tail-hole cutout, flexible waistband, and multi-channel instant dispersion.
- **Interactive Sizing Matrix**: Live dimension, waist fit, and absorbency tabs across S, M, L, and XL sizes.
- **5-Layer Training Pad Explorer**: Click-to-inspect layer architecture detailing Diamond-Quilted Non-Woven Top Sheet, Fast-Dispersion Tissue, Sumitomo SAP Core, Structural Reinforcement Tissue, and 100% Waterproof PE Backsheet.

### 3. OEM & Private Label Solutions
- **Structured 5-Stage Sourcing Workflow**: Product Selection → Specification Review → Packaging Customisation → Quality Verification → International Shipping.
- Full support for custom die-lines, multi-language retail packaging, private-label barcodes, and container load optimization (20GP / 40HQ).

### 4. Quality Assurance & Audited Standards
- ISO 9001:2015 certified manufacturing partner facilities.
- Strict adherence to AQL 2.5 quality control standards, in-line SAP absorbency verification, tensile seal strength checks, and microbial cleanliness testing prior to container dispatch.
- Transparent separation of manufacturing quality standards from global logistics network accreditations.

### 5. Multi-Channel RFQ Quotation Engine
- Replaces speculative consumer pricing calculators with an authentic B2B quotation process.
- Prospective buyers specify target products, sizes, volume tiers (Trial 5k, 10k, 20ft FCL, 40ft HQ), destination port, and Incoterm (FOB, CIF, DDP).
- Direct one-click quotation dispatch via **Official Business Email** or **Primary WhatsApp Desk**.
- Pre-formatted text summary clipboard generator for corporate procurement requests.

## 🚀 Local Development

To run the portal locally:

```bash
# Clone the repository
git clone https://github.com/niloy-datta/shl-pet-care-showcase.git
cd shl-pet-care-showcase

# Start local server
python -m http.server 3000

# Open in browser:
# http://localhost:3000
```
