## 🌟 Key Features

- **Device-Friendly & Responsive Architecture**: Built with CSS Container Queries (`@container emailbox`) ensuring pixel-perfect layout across Mobile (390px), Desktop (660px standard email preview width), Phone Mockup Frame, and Expanded display modes.
- **Self-Contained Offline Assets**: All product diagrams, exploded graphics, packaging dimensions, and verified accreditation logos (ISO 9001, WCA ID 116248, DF Alliance, JCtrans, TCDA, Millennium Logistics) are embedded as high-fidelity Base64 data URIs.
- **Interactive Wholesale ROI & Margin Calculator**: Real-time pricing model calculating savings, profit margins (up to 55%), and annual financial benefits for international distributors and retail chains.
- **Evaluation Sample Pack Customizer**: Interactive checklist allowing prospective buyers to configure custom test boxes (Male Wraps, Female Diapers with tail holes, 5-layer Sumitomo SAP training pads, and charcoal odor pads) with one-click WhatsApp/Email pre-filled RFQs.
- **B2B Strategy Drawer**: Commercial buyer checklist, container load capacities (20GP / 40HQ), and direct factory terms.
- **One-Click Email Template Exporter**: Modals for instant HTML/Plain-Text email copying ready for Outlook, Gmail, Klaviyo, or Mailchimp.

## 🚀 Quick Start (Localhost)

To view the showcase locally:

```bash
# Clone the repository
git clone https://github.com/niloy-datta/shl-pet-care-showcase.git
cd shl-pet-care-showcase

# Start local HTTP server
python -m http.server 3000

# Open in browser:
# http://localhost:3000
```
